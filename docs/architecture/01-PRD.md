## 1. Бачення

VIDEO COMBINE AI — автономна, модульна AI-студія виробництва YouTube-відео.
Користувач подає тему, URL продукту, текст, зображення, відеофайл або авторизоване
джерело — система повертає повністю змонтоване, оригінальне, професійно
оформлене відео разом із мініатюрою, SEO-метаданими та звітом якості.

Ключова відмінність від конкурентів (MoneyPrinterTurbo, ViMax, agnes-video,
MoneyPrinterPlus): **ядро працює без жодного API-ключа**. Хмарні сервіси —
опційні адаптери, а не передумова роботи.

## 2. Проблема та цінність

| Проблема ринку | Відповідь VIDEO COMBINE AI |
|----------------|----------------------------|
| Потрібні ключі Pexels/ElevenLabs/OpenAI | Keyless-ядро: Wikimedia/NASA/Archive.org, edge-tts/Piper/SAPI, локальні моделі |
| Платні генерації «з коробки» | Локальні рушії за замовчуванням; хмара — явний opt-in |
| Чорна скринька генерації | Кожен етап має схеми вводу/виводу, логи, людину-затверджувача |
| «Перепаковані» чужі ролики | Реальна редактура: монтаж, коментар, субтитри, походження збережено |
| Неможливо відновити після збою | Orchestrator з control-plane і resume |

## 3. Цільові користувачі

1. **Українськомовний автор** — створює довгі ролики та Shorts без ключів.
2. **Англомовний автор** — ті самі сценарії з англійськими голосами/метаданими.
3. **Власник продукту** — подає URL/фото й отримує рекламний ролик.
4. **Редактор** — використовує Clip Studio для авторизованих вихідних роликів.
5. **Розробник/оператор** — розширює агенти й скіли, керує чергою рендерів.

## 4. Обсяг

### 4.1 Входить у скоуп

- Ukrainian + English, long-form + Shorts, 16:9 + 9:16, 1080p + 720p.
- 9 спеціалізованих агентів + Orchestrator.
- FFmpeg як ядро рендерингу; H.264 MP4; збережуваний таймлайн.
- Scene-based editing, переходи, мікс аудіо, синхронізація голосу, музика,
  анімовані субтитри, текстові оверлеї, анімація зображень, інтро/аутро.
- Пошук і ранжування ліцензованого стоку; завантаження користувачем медіа.
- Clip Studio для **авторизованих** джерел: аналіз, детекція сцен, цікавих
  моментів, автоматичний відбір, рефреймінг, новий коментар і структура.
- Генератор мініатюр (16:9 / 9:16), кілька варіантів, редаговані шари.
- SEO: заголовки, описи, теги, хештеги, ключові слова, закріплені коментарі.
- FastAPI backend + React/Next.js dashboard (11 розділів).
- SQLite → PostgreSQL, Redis + Celery, Docker.
- pytest + frontend-тести, AGENTS.md, скіли у version control.

### 4.2 Явно не входить

- VPN/анти-DPI/ротація проксі/Telegram-транзит зі списків «Партія 26» —
  каталогуються лише як `out-of-scope`.
- Приховання авторства, обхід Content ID, маніпуляція метаданими як спосіб
  обійти захист авторських прав.
- Обов'язкові платні сервіси, хардкод секретів, автоматична генерація без
  явного схвалення користувачем платних дій.
-_retired_/`reference-only` репозиторії (Chatterbox, MoneyPrinterPlus тощо)
  не імпортуються й не копіюються.

## 5. Функціональні вимоги

### F-R2. Проєкт і вхідні дані
- **FR-01** Створення проєкту з теми, URL, тексту, файлів або авторизованого джерела.
- **FR-02** Вибір мови (`uk`/`en`), формату (`long`/`short`), співвідношення
  (`16:9`/`9:16`), профілю (`1080p`/`720p`).
- **FR-03** Збереження чернетки й відновлення перерваного завдання з будь-якого етапу.
- **FR-04** Людське затвердження/редагування проміжних результатів (research,
  script, сцен, план медіа, мініатюра, SEO).

### F-R3. Агенти
- **FR-10 Research Agent**: збір фактів із keyless/авторизованих джерел, список
  джерел і дат, відмова від непідтверджених тверджень.
- **FR-11 Script Agent**: оригінальний сценарій + покроковий план сцен
  (тривалість, візуал, текст оверлею, настрій, перехід).
- **FR-12 Voice Agent**: uk/en озвучка через драбину `tts_save`
  (edge → Piper → Kokoro → SAPI → silence), word-level timing, SRT.
- **FR-13 Media Agent**: пошук, ранжування за релевантністю до сцени,
  відсіювання непридатних кадрів, облік ліцензії й джерела, завантаження
  тільки дозволеного, підтримка користувацьких файлів.
- **FR-14 Clip Agent**: аналіз авторизованого відео, детекція сцен/моментів,
  відбір, вертикальний/горизонтальний рефреймінг, новий коментар і структура.
- **FR-15 Thumbnail Agent**: 16:9/9:16, AI-композиція або шаблон, продукт,
  текст, шрифти, кілька варіантів, редаговані шари, експорт PNG.
- **FR-16 SEO Agent**: title/description/tags/hashtags/keywords/pinned comment,
  окремі набори для long-form і Shorts, uk/en.
- **FR-17 Editing Agent**: складання фінального таймлайну, аудіомікс, субтитри,
  оверлеї, інтро/аутро, переходи, рендер H.264 MP4.
- **FR-18 Quality Agent**: валідація тривалості, чорних кадрів, LUFS, ASR-звірки
  субтитрів, синхронізації, наявності атрибуції; формує звіт і блокує реліз.
- **FR-19 Orchestrator**: керування повним конвеєром, залежностями, повторними
  спробами, паузами на затвердження, resume після збою.

### F-R4. Монтажний двигун
- **FR-20** FFmpeg-рендер із scene-based таймлайном, збереженням проекту
  (editable project file) і структурною інформацією про шари.
- **FR-21** Переходи (fade/dissolve/wipe), аудіомікс (голос/музика/SFX),
  нормалізація гучності.
- **FR-22** Анімовані субтитри й текстові оверлеї з word-level timing.
- **FR-23** Анімація зображень (ken-burns/parallax), інтро/аутро.
- **FR-24** Конвертація співвідношення (crop/pad/blur-bg), профілі 1080p/720p.

### F-R9. UI та операції
- **FR-30** Дашборд з розділами: New Video Project, Product Video Generator,
  YouTube Clip Studio, Script Editor, Voice Studio, Media Library, Thumbnail
  Studio, SEO Studio, Rendering Queue, Completed Projects, Settings.
- **FR-31** Моніторинг кожного етапу в реальному часі + ручне затвердження.
- **FR-32** Black-box логи, метрики часу/вартості, можливість перезапуску етапу.
- **FR-33** SQLite для локального режиму; шлях міграції на PostgreSQL.
- **FR-34** Redis + Celery для черги рендерів (опційно в локальному режимі).

## 7. Критерії прийняття (вищого рівня)

- Keyless smoke: `python -m generator "..."` і повний конвеєр дають MP4 без ключів.
- Дві мови × два формати × два співвідношення × два профілі — матриця приймається.
- Усі 9 агентів мають тести, схеми, SKILL.md і логи.
- Quality Agent блокує реліз за наявності чорних кадрів/розсинхрону/відсутньої атрибуції.
- `make test` зелений; frontend-тести зелені; Docker-образ збирається.
- Жодного секрету в `git log`/`.env.example`; платні дії — тільки явний opt-in.

## 8. Обмеження та припущення

- Поточний стенд: Python 3.11.18, Node 22.23.4, FFmpeg 9.0.2, GNU Make 3.81,
  **без CUDA/MPS** — GPU-рушії лише каталогуються й активуються явними `*_REPO`.
- Мережеві обмеження: `loc.gov` віддає Cloudflare 403; дефолт — Wikimedia/NASA/Archive.org.
- Piper/MediaPipe вимагають ASCII-шляхів на Windows (кеші в `C:/omtest/...`).
- `REPLICATE_API_TOKEN`/`PIXABAY_API_KEY` перевірка заблокована Cloudflare 1010 —
  статус «записані, не перевірені», не є частиною keyless-ядра.
- Mistral browser auth розглядається **тільки для розробки**, не як виробничий
  механізм і не як заміна keyless-режиму.
